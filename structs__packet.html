Detailed Description

This is the serialized varient of v_packet. You as the dev shouldnt directly manipulate this, (unless you want to). This basicly is a v_packet, but all the data is smooshed and copied into a flat buffer. Because it is now a flat buffer, it can be easily sent over the network.
